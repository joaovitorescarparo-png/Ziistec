# ZiisTec

Plataforma para prestadores de serviços técnicos, com clientes, ordens de serviço, agenda, orçamento, financeiro, equipe e integração com Supabase.

## Deploy

Projeto preparado para Vercel. Os arquivos grandes do pacote original são reconstruídos no `prebuild` com verificação SHA-256 para garantir integridade byte a byte.
